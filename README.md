# بوت تداول Binance (Python)

بوت تداول آلي لسوق Spot على Binance. يعمل بثلاثة أوضاع:

| الوضع | الأمر | المال |
|---|---|---|
| اختبار تاريخي | `python -m bot backtest` | لا يوجد |
| تداول ورقي | `python -m bot paper` | وهمي، بأسعار حقيقية |
| تداول فعلي | `python -m bot live --live` | حقيقي (Testnet أو الحساب الفعلي) |

> ⚠️ **تحذير:** لا يوجد نظام يضمن الربح. الأداء السابق في الاختبار التاريخي لا يعني ربحاً في المستقبل.
> ابدأ دائماً بالاختبار التاريخي، ثم بالتداول الورقي لعدة أسابيع، ثم بالـ Testnet، وبعدها فقط بمبلغ صغير تتحمّل خسارته.

## الاستراتيجية

- **الدخول (شراء):** المتوسط الأسي السريع `EMA 12` يقطع البطيء `EMA 26` صعوداً، بشرط أن يكون `RSI < 70` (أي أن السعر غير مُشبع شرائياً).
- **الخروج (بيع)** عند تحقق أول شرط من هذه:
  - وقف الخسارة: سعر الدخول − 2 × ATR
  - جني الربح: سعر الدخول + 4 × ATR (نسبة عائد إلى مخاطرة 1:2)
  - تقاطع EMA هبوطاً
- **شراء فقط (Long-only)،** بدون رافعة مالية أو بيع على المكشوف.
- تُتخذ القرارات على **الشمعة المغلقة فقط**، أما وقف الخسارة وجني الربح فيُفحصان مع كل تحديث للسعر.

## إدارة المخاطر

- **حجم المركز:** يُحسب بحيث تخسر 1% فقط من رأس المال إذا ضُرب وقف الخسارة (`RISK_PER_TRADE`).
- **سقف المركز:** لا يتجاوز المركز 25% من رأس المال (`MAX_POSITION_PCT`).
- **حد الخسارة اليومي:** يتوقف البوت عن فتح صفقات جديدة بعد خسارة 3% في اليوم (`MAX_DAILY_LOSS_PCT`).
- **حفظ الحالة:** يُحفظ المركز المفتوح في ملف `state.*.json`، فإذا أُعيد تشغيل البوت لا يفقد وقف الخسارة.
- **ثلاث طبقات أمان للتداول الحقيقي:** المتغير `LIVE_TRADING=true`، والخيار `--live`، ثم كتابة `YES` يدوياً عند استخدام الحساب الفعلي.

## التثبيت

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # ثم عدّل القيم
```

## الاستخدام

```bash
# 1) اختبار تاريخي على بيانات سنة كاملة (بيانات عامة، لا يحتاج مفاتيح API)
python -m bot backtest --days 365 --save data/btc_1h.csv --trades

# إعادة الاختبار من الملف المحفوظ بعد تعديل الإعدادات
python -m bot backtest --csv data/btc_1h.csv

# 2) تداول ورقي: أسعار حقيقية ومال وهمي
python -m bot paper

# 3) Testnet: احصل على مفاتيح من https://testnet.binance.vision
#    واضبط BINANCE_TESTNET=true و LIVE_TRADING=true في ملف .env
python -m bot live --live
```

تُكتب السجلات في `logs/bot.log`.

## مفاتيح API — قواعد أمان

1. فعّل صلاحية **Spot Trading فقط**، و**عطّل السحب (Withdrawals) نهائياً**.
2. قيّد المفتاح بعنوان IP الخادم الذي يعمل عليه البوت.
3. ملف `.env` مُدرج في `.gitignore`. لا ترفعه أبداً ولا تشاركه مع أحد.

## هيكل المشروع

```
bot/
  config.py      الإعدادات من .env مع التحقق من صحتها
  indicators.py  EMA و RSI و ATR (بطريقة Wilder)
  strategy.py    توليد إشارات الشراء والبيع
  risk.py        حجم المركز، والوقف، وحد الخسارة اليومي
  exchange.py    الاتصال بـ Binance عبر ccxt وجلب الشموع
  broker.py      منفّذ ورقي (Paper) ومنفّذ حقيقي (Live)
  engine.py      حلقة التداول وحفظ الحالة
  backtest.py    الاختبار التاريخي مع العمولات والانزلاق السعري
tests/           اختبارات الوحدة، ومنها اختبار عدم استخدام بيانات المستقبل
```

تشغيل الاختبارات:

```bash
pytest -q
```

## ملاحظات مهمة

- **الوقف يديره البوت نفسه:** وقف الخسارة وجني الربح ليسا أوامر موضوعة على المنصة، بل يراقبهما البوت. إذا توقف البوت عن العمل فلن يُنفَّذ الوقف. شغّله على خادم دائم (VPS) مع `systemd` أو `docker` مع إعادة تشغيل تلقائية.
- **الاختبار التاريخي واقعي:** ينفّذ الأمر على سعر افتتاح الشمعة التالية. وإذا لمست الشمعة نفسها الوقف والهدف معاً، يفترض أن الوقف ضُرب أولاً (افتراض متحفّظ).
- **تجنّب الإفراط في الملاءمة:** لا تعدّل المعاملات حتى تحصل على أفضل نتيجة على نفس البيانات. اختبر على فترة لم تستخدمها في الضبط (Out-of-sample).
